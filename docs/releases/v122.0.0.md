# Receiz v122.0.0

Release date: 2026-08-21

v122 ships remote durable proof-object subjects, edge-encrypted private world events, exact execution recovery, strict transaction validation, remote mandates, atomic multi-world mechanics, canonical SDK helpers, and explicit Phi Settlement and Reserve rails.

The proof object is authority. The SDK verifies and carries exact edge truth; the production application API and database coordinate synchronization, append serialization, replay, and recovery. The settled Receiz application experience and first-paint paths remain unchanged.

## Shipped outcome

External developers can admit verified proof objects as durable subjects, carry
their complete authenticated state at the edge, exchange encrypted private
world additions, recover exact transaction outcomes, delegate bounded mandates,
and compose atomic multi-world work. Value moves only as Phi through the named
Settlement or Reserve rail; USD remains a deterministic display projection.

## What changed

- Added remote subject admission, authenticated state, edge export, and verified recovery.
- Added locally encrypted private/invited world envelopes and append-only access state.
- Added strict transaction validation, durable outcome lookup, mandates, and multi-world atomic execution.
- Added explicit Phi Settlement and Reserve planning plus canonical validation helpers.
- Added matching SDK, MCP, and AI skill developer surfaces without changing settled Receiz application paths.

## Institutional boundary

V122 establishes one end-to-end institutional contract for external developers: the enclosing proof object is authority; held edge material is the complete lawful operating basis; verified appends provide coordination; and database, API, MCP, AI, session, index, and display layers remain subordinate distribution and recovery mechanics. No service response, stored row, model output, receipt projection, or USD display can mint, replace, or overrule proof-object authority.

Remote subject admission, owner/head-bound access rotation, private/invited world envelopes, exact execution recovery, validation, mandates, multi-world atomicity, and Phi movement therefore share one authority chain. Phi moves only through the named Settlement or Reserve rail. Canonical deterministic prices may display live USD without making USD the moved authority.
