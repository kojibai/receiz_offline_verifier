## Authority before arithmetic

Do not begin with a value shown by a page or API. Begin with the enclosing sealed proof object.

5. Run the exact v125 projector and compare the returned integer micro-Phi value.

This order is mandatory: source → evidence → relationship → permissible inference → representation. Never backward.

```ts

  pulse: C,

  stepIndex,

  quality: "high",

valuePhi = Number.isFinite(valuePhiRaw) && valuePhiRaw > 0 ? valuePhiRaw : 0
```
