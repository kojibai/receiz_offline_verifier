# Receiz v128.0.0 Migration

This distribution inherits the exact admitted v127 registry and preserves established wire schemas, source bytes, identity, custody, temporal proofs and application behavior. No production SQL or registry migration is introduced. The [registry binding](v128.0.0-registry-binding.json) binds the exact historical artifact and digest.

Package compatibility advances to `>=128.0.0 <129.0.0`; SDK, MCP and AI skills all declare `128.0.0`. Install or publish them together. Publish `@receiz/ai-skills` first, `@receiz/sdk` second and `@receiz/mcp-server` third, because the latter packages declare exact dependencies. The repo commands run the shared qualification before publication.

Do not clear durable local truth, reissue known Identity Seals, reseal Originals, rewrite histories or replace the independently qualified Mind installer as an upgrade step. App and PWA release markers change only to distinguish the new build. Full freeze, account-entry and source/continuity gates must pass before delivery.
