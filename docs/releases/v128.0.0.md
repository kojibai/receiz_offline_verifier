## Release outcomes

**Carry the source once. Continue from it everywhere.** Receiz removes the need to reconstruct authority from mutually inconsistent representations. Exact sealed sources carry identity and evidence; admitted history carries continuity; readers derive permitted state; authorized actors append under the existing law. A portable object does not require its originating application to remain the authority for its history.

The institutional value is upstream: preserve what establishes a fact before it becomes a copied report, disconnected record, unsupported AI answer or disputed handoff. Distribute useful evidence with intentional scope, retain independent verification, and keep applications replaceable beneath the source. This does not turn a proof of integrity into proof that every reported real-world statement is true, grant access through a QR tag, or remove an institution's legal retention obligations.

## AssetSeal: the physical asset carries its history

QR generation and explicit camera scanning identify the same asset; the tag grants no authority.

The implemented path is issue → identify → owner-authorized record → attach evidence → derive recorded state → export the sealed workspace → independently verify and reconstruct it offline. Held asset records paint from local custody. Attachment descriptors support the immediate index; exact attachment bytes remain in admitted storage and resolve on inspection. Native photo/video capture is available where the device supports it.

Scoped third-party service authority, independent accreditation/revocation, cross-owner transfer, selective disclosure and a connected reasoning model are separate incomplete application compositions, not features implied by the console's visual design.
