# Receiz v114.0.0 Product Truth

The public package surface is `@receiz/sdk`. Durable proof memory remains **first admission only, then append forever**.

## Frozen Primitives

### Profile showcase proof object

The profile showcase is a sealed composite proof object with stable identity `profile-showcase:<Receiz ID>`. Every accepted state is a sealed successor carrying the exact predecessor, one bounded delta, deterministic commitment mechanics, carried history, immutable segment references, and a sealed first-paint window.

### Economy showcase proof object

The economy showcase is a sealed recursive composite proof object with stable identity `economy-showcase:receiz.com`. It appends exact admitted profile showcase heads. A profile is not re-described or reconstructed to enter the economy; its admitted proof identity and evidence remain intact.

### Market public proof surface

Market is a deterministic digest-bound projection of the admitted economy proof. It is not the economy authority. It may rebuild from the exact verified head without changing proof history.

### Identity custody

The accepted Identity Record is the actor authority for profile transitions. Custody preserves that proof across creation, export, Receiz Key restoration, hard reload, and explicit unlock. Session state may clear or scope custody but cannot manufacture identity authority.

## Truth Order

For the v114 showcase path, authority remains:

1. sealed Original and Identity Record proof objects
2. sealed profile showcase successor
3. sealed economy showcase successor
4. verified durable edge custody and carried history
5. exact-digest public/Market projection
6. coordination, database, session, and UI state

Merkle roots, Fibonacci checkpoints, migration indexes, lookup rows, manifests, and caches are deterministic mechanics. They never outrank the enclosing sealed carrier.

## Frozen Invariants

The release must fail if any future change:

- treats a profile array, database row, snapshot, or cache as the profile proof authority
- accepts a resulting showcase state without sealing that state as a successor proof object
- appends a reconstructed profile description to the economy instead of the exact admitted profile head
- lets a Market projection select an older profile head over its verified descendant
- rebuilds complete profile/economy history on the foreground append path
- rediscoveries known verified truth before deterministic first paint
- lets missing edge state blank stronger server-rendered truth
- creates an empty genesis for an existing profile without complete truthful migration
- drops a failed economy append without durable retry
- advances an economy head without comparing the exact active predecessor, including bootstrap from `null`
- uses cumulative count or direct-child evidence as a substitute for historical economy membership proof
- lets a visibility database write leave the bounded profile/economy proof stale and authoritative
- lets a stale bounded head resurrect a hidden Original
- silently skips composer proof settlement when Identity Record custody is locked or unavailable
- retains signing custody after logout
- lets a stale async custody finalizer repopulate custody after logout or newer identity admission
- persists an expiring signed URL as permanent public proof action
- lets an unbounded certificate/key cache grow with attacker- or device-controlled identities

## Scale Truth

The foreground append cost depends on bounded head state and the new delta, not total historical cardinality. Executable contracts prove profile append at 100,000 and 1,000,000 prior children and economy append at 1,000,000 prior profiles.

This proves the bounded append architecture at those cardinalities. It does not claim infinite physical storage, zero archival cost, or zero network transport. Archive compaction remains explicit linear maintenance outside first paint and foreground append.

## Compatibility Truth

V114 adds new registered proof carriers and transition laws. It does not mutate prior sealed proof objects or redefine the v113 coordination rail. Legacy profile history enters v114 only through deterministic reverification, ordered adoption, committed exceptions, and fail-closed cutover.

The v114 registry digest is `ae912154d97b695464c3a19361bceb9440bc5d703a1d9129edac92c64192e29a`, chained to v113.

At the documented fixed-code head, v114 remains additive to package/release identity `113.5.0`. Package promotion is not proof truth and has not been represented as complete.

## First-Paint Truth

Known verified edge truth paints immediately. Background work may append verified additions, reconcile siblings, rebuild subordinate projections, or retry economy admission without remounting or redefining the settled visible surface.

A pending visibility transition is exact contradictory evidence against the predecessor’s visibility projection. That predecessor is quarantined until its sealed successor is admitted; weaker server truth may remain visible, but stale bounded truth may not overwrite it.
