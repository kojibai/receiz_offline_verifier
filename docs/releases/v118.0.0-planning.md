# Receiz v118.0.0 Planning Boundary

Receiz v118.0.0 is the shipped coordinated major-release baseline. Its release
record is [v118.0.0](./v118.0.0.md); it does not claim the deferred orchestration
program as implemented.

[v119.0.0 implementation plan](./v119.0.0-planning.md). V119 inherits the
immutable v118 registry, exact SDK/MCP/AI operation matrix, package identity,
proof-object authority, offline verification, deterministic first paint, and
publication blockers.
