# Receiz v117.0.0 Regression Lessons

## What Regressed

Contacts/PWA continuity, Profile settled surfaces, Wallet/Glyph settlement retention, Sports live/save paths, transaction Moment collection, and several release contracts had diverged from settled law during the post-v116 work.

## Why It Regressed

Weaker projections or refresh mechanics were allowed to compete with held proof truth; service-worker work entered visible continuity; an existing sealed Moment was incorrectly routed through resealing; and some tests pinned mutable time or obsolete product wording.

## Locked Rules

- A partial Contacts, Profile, showcase, wallet, or sports projection must never erase stronger held proof truth. Rank and merge by proof authority, then append.
- Service-worker sophistication can directly regress settled UX. Versioned asset delivery is allowed; refresh loops, visible remounts, truth deletion, and tap-path work are forbidden.
- First paint is not a place for rediscovery. Redis, DB, session, SEO, share metadata, global sync, and network work stay behind the settled shell.
- Offline verification and transaction Moment collection reuse the existing sealed artifact. Resealing creates a false authority boundary and produces dishonest failure states.
- Source-size work must preserve execution semantics. A direct hook extraction is acceptable only when import timing, custody, effect timing, messages, and visible behavior remain exact.
- A release gate should distinguish unavailable infrastructure from failed law. Missing isolated DB credentials may skip only that destructive fixture; they must not hide or prevent other tests.
- Time-sensitive fixtures must inject deterministic time. A test that expires because wall-clock time advanced is not a valid product-law failure.
- Tests must follow literal product law. They may be corrected when stale, but never changed to approve contradictory visual evidence or weaker product behavior.
- Coordinated releases require every current identity surface to move together. Historical v116 constants remain immutable evidence; stale current v116 labels are release failures.
- Planning is not shipment. Deferred orchestration work moved to v118 and is explicitly excluded from v117 product truth.

## Contract Gates

Deterministic surfaces, page-first-paint, visual evidence, primitive binding, repo-only reasoning, continuity, game release, `/t/` and `/v/` share, transaction Moment collection, coordinated packages, SDK/MCP/AI distribution, and full release freeze contracts guard these rules.

For `@receiz/sdk` v117, durable proof memory remains **first admission only, then append forever**.
