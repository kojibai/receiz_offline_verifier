# Receiz v124.0.0 Runbook — Reality Becomes Infrastructure

**The Production Runtime for Verified Civilization.** Operators preserve the sealed proof object and exact authenticated head while restoring sync and recovery infrastructure beneath them.

## Qualification failure

Keep the runtime closed. Inspect each required dependency's evidence, not method presence. Restore journal/checkpoint, plan storage, transaction context, revocation, access filtering, or recipient resolution independently; then rerun qualification. Never bypass qualification by converting a configured dependency into an operational claim.

## Ambiguous execution

Do not resubmit. Resolve the original idempotency key. Accept only a request-bound authenticated outcome:

- `committed`: verify the exact prior and accepted heads and project once.
- `zero-write`: verify that no declared domain advanced before deciding whether a new plan is lawful.
- `unknown`: keep the operation unresolved and investigate durable plan/journal evidence; unknown is not retry permission.

## Replay or checkpoint failure

Reject the entire addition set before callbacks. Preserve the last verified local head, inspect signature/proof, predecessor, namespace metadata, expiry, revocation, and discriminator/status validation, and request only additions after that verified head.

## Private-access or recipient event

Stop hydration or resolution at the boundary. Preserve private ciphertext and coordinates, rotate affected rate limits or grants through existing authority flows, and verify that no unauthorized application callback received the data. Do not create a new issuer or admission path as remediation.

## Atomic transaction failure

Verify every declared domain remained at its prior exact head. Any partial accepted write is release-blocking. Repair transaction coordination below proof authority and replay only from the verified predecessor.

No runbook action changes the law that durable proof memory is first admission only, then append forever. Production execution of this runbook has not been evidenced for the V124 candidate.
