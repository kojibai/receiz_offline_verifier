# Receiz v114.0.0 Performance Findings

The public package surface is `@receiz/sdk`. Durable proof memory remains
**first admission only, then append forever**.

## Foreground Bound

Profile append cost is a function of one admitted child, one compact prior
head, bounded Merkle carry work, sparse Fibonacci checkpoint work, one
coordination write, and one derivative effect. It is not a function of the
complete historical profile array.

The same recursive bound applies to one profile successor entering
`economy-showcase:receiz.com`. Market derives from the admitted economy digest;
it does not rediscover every profile as a prerequisite for foreground
settlement.

Executable upstream evidence covers:

- one bounded profile append after 100,000 admitted children
- one bounded profile append after 1,000,000 admitted children
- one bounded economy append after 1,000,000 admitted profile heads
- scale metrics free of artifact bytes, private URLs, credentials, content,
  and complete historical arrays

## First-Paint Bound

A verified held profile head paints before network discovery, database
reconstruction, session lookup, migration, or economy synchronization. A
verified held economy head paints its exact-digest Market projection before
weaker refresh work.

Background discovery may append verified additions. It may not remount, blank,
or redefine settled visible truth. Pending visibility contradiction
quarantines the known-stale predecessor without turning deterministic first
paint into generic loading state.

## Maintenance Boundary

Physical archive compaction is explicitly linear maintenance. It remains a
separate soak and is not included in foreground append or first-paint claims.
The release therefore claims bounded foreground work at the tested
cardinalities, not infinite storage, zero archival cost, or zero transport.

## Runtime Memory

Device-certificate verification and imported Ed25519 key caches are bounded.
Invalid certificate results cannot grow without limit. Identity custody is
generation-bound so logout or newer admission prevents stale async work from
repopulating cleared authority.

## Exact Limitations

The upstream production build retains the recorded Groth16
dynamic-dependency warning, and upstream lint records 27 unused-symbol
warnings with zero errors. This standalone verifier’s own `pnpm lint` and
`pnpm build` gates must pass from the exact release tree; neither result
rewrites the upstream evidence.

The authenticated composer ritual and complete profile media first paint
remain visually unproven. Performance gates cannot contradict that evidence
boundary.

## Release-Lock Requirement

`pnpm release:lock 114.0.0` must require this record. No future release may
move complete-history reconstruction, migration, economy retry, or archive
compaction into deterministic first paint or the foreground append path.
