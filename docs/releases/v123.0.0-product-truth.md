The main receiz.com user experience is not redesigned by v123. Visible changes are limited to developer documentation and current release identity. No new foreground session, DB, network, hydration, or first-paint dependency is introduced into existing user surfaces.

The public developer abstraction intentionally exposes supported operations and withholds internal tables, RPC names, administrative routes, session mechanics, and implementation-only media plumbing. Six new HTTP operations are public; canonical local planners and helpers remain SDK operations rather than invented endpoints.
