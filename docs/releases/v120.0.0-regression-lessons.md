# Receiz v120.0.0 Regression Lessons

Developer surface: `@receiz/sdk@120.0.0`. Durable proof-memory law: first admission only, then append forever.

## What Regressed

- A fixed prompt window is not a brain. Preserve complete proof history and bound only retrieval.
- An index is a locator. Resolve exact primary proof-object bytes before reasoning or narration.
- Fast streaming comes from compact causal heads and segmented retrieval, not from dropping history.
- Model fluency cannot become world authority. Speech and performance survive failure independently of canonical state.
- Mutual effects cannot be implemented as sequential one-sided writes.
- Revocation is checked when work executes, not only when it was queued.
- Idempotency and replay protection are different: the same attempt may return its receipt; another claimant cannot reuse it.
- Ownership transfer changes authority and custody, not subject identity or history.
- Unknown namespaces are future application truth and must never be normalized away.
- A released complete profile count cannot be replaced by a stale projection.
- An opened long-form reader is settled. Background narration discovery may prepare the next interaction but cannot add a play control to the already-open surface.

## Why It Regressed

Current release identity, complete-history retrieval, proof-coordinate fallbacks, narration readiness, and package entry conditions were implemented in separate eras. The gaps appeared where a bounded projection or stale release pin was allowed to stand in for the stronger complete artifact contract.

## Locked Rules

- Canonical head resolves the entire content-addressed history; only the reasoning window is bounded.
- Indexes locate exact primary objects and never replace them.
- Payload-carried legacy anchor IDs preserve the enclosing proof object's access coordinate.
- Play appears only for a verified ready derivative bound to the exact source digest.
- Model, MCP, receipt, projection, and server output never create proof authority.

## Contract Gates

The v120 release lock, living-subject conformance, narration integration, service-worker/offline freeze, SDK/MCP/AI package tests, world replay suites, full release freeze, build, visual evidence, governance, and attestation contracts prevent recurrence.
