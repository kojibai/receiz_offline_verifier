# Receiz v126.0.0 Compatibility

| Subject | Compatibility boundary |
| --- | --- |
| Coordinated packages | SDK, MCP and AI skills use 126.0.0; current integrations require >=126.0.0 <127.0.0. |
| Compiler | New admissions use the exact v126 registry; historical targets retain their original registry identities. |
| Historical proof objects | Original bytes, creation coordinates, ownership history and registry digests remain unchanged. |
| Wire protocols | Existing versioned SDK exports, MCP tool identifiers, KKSv1.0 and Signature V4 retain their established names. |
| Current JSON schemas | The v126 schema directory binds the current registry while preserving established wire schema identifiers; v125 schemas remain available for historical records. |
| Function discovery | @receiz/sdk/function-inventory exposes the full callable export catalog without adding that data to the universal runtime entry point. |
| SQL admission | The additive registry successor migration is required before the existing hosted admission functions accept v126. |
| First paint | Complete known published Showcase truth remains visible while a newer publication is pending. |
