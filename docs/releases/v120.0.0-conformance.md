The `livingSubject` suite must independently prove:

1. No model statement becomes an event without typed command admission.
2. Every factual memory cites admitted event IDs.
3. Multi-subject effects are atomic.
4. Retry cannot duplicate an event.
5. A revoked mandate cannot execute.
6. Offline restoration preserves exact state.
7. Independent replay produces the same heads.
8. SDK and MCP reads produce equivalent projections.
9. Unknown namespaces survive every transition.
10. Conversation and animation failure cannot corrupt canonical state.

## Bearer-transfer laws

The same release suite must prove:

1. A second distinct claim is rejected while an idempotent retry returns the original receipt.
2. A stale ownership head is rejected.
3. Cancelled and expired instruments are rejected.
4. The former owner cannot use private Twin or world authority after claim.
5. A queued former-owner mandate cannot execute.
6. The new owner receives the exact same subject identity and complete history.
7. Unknown namespaces survive transfer byte-for-byte.
8. A failed transfer produces zero state changes.
9. Offline instrument inspection followed by online claim converges to the same ownership head.
