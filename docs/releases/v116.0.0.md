# Receiz v116.0.0

@receiz/sdk preserves durable proof memory: first admission only, then append forever.

Release date: 2026-07-30

## The current product. Sealed.

V116 promotes the proven baseline at `0820771f7` without introducing a new
authority model or orchestration layer.

Core creation, identity, proof, ownership, verification, and sharing remain
free. Premium powers Creator and Live Twin AI. Business adds production API
execution. Purchased AI credits remain non-expiring and reconcile across
checkout, refunds, and payment disputes.

## First use, made direct

New accounts now start with one useful act: create a post in Composer.

1. Set up the place that proves.
2. Create your first post.
3. Add a cover.
4. Copy your link.

No Twin setup is required to learn Receiz or publish a verified Original.

## Continuity

- Active signed subscription terms reach Business Creator execution.
- Lost payment disputes revoke purchased credits; later wins restore them
  idempotently.
- Hosted checkout returns reconcile paid credits without a stale balance.
- Accepted PBI identity proof remains visible when the owner leaves and returns.
- Known proof paints first. Server refresh may append; it may not erase.
