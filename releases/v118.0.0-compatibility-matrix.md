## Publication law

SDK, MCP, and AI prepack/prepublication hooks call the root coordinated release
identity contract. Publication must stop before a registry upload if any
current identity differs. The coordinated package gate additionally builds
tarballs, installs them into a clean consumer, imports only package exports,
recomputes the matrix digest, and compares every AI manifest to SDK and MCP.

## Artifact compatibility

V118 does not introduce a new verifier or transaction authority. The collected
transaction image uses the existing carrier append, artifact anchor, Signature
V4, Groth16, and unchanged canonical offline verifier. Tampering with the exact
embedded transaction invalidates artifact binding.
