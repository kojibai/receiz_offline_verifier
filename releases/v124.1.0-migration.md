# Receiz v124.1.0 Migration

**Reality Becomes Infrastructure — The Production Runtime for Verified Civilization.**

No artifact, registry, database, identity, conversation, ownership, or settlement migration is required. Existing sealed proof objects remain exact-byte valid. Previously sealed V1 portable-completeness claims retain their original pre-market domain semantics; new complete exports emit V2 and include market continuity.

Developers adopting the coordinated packages should:

1. Upgrade `@receiz/sdk`, `@receiz/mcp-server`, and `@receiz/ai-skills` together to `124.1.0` after publication.
2. Import `RECEIZ_V124_1_CAPABILITY_INVENTORY` and expose only the capability families the trusted host actually supports.
3. Publish complete RMC2 packages before advertising public coordinates.
4. Dispatch raw material by `capsuleEncoding` and retain RMA2/RMC1 compatibility.
5. Use signed progressive ledgers for range playback and retain whole-artifact fallback.
6. Keep source bytes, conversation cleartext, epoch secrets, private memory, and identity-carried private state out of MCP/model output.

Institutional, governmental, corporate, or platform deployment does not change any verification requirement.
