## Documentation and distribution procedure

The main record, product truth, compatibility, conformance, checklist, lessons and commit ledger form the v128 release preparation set. Historical releases remain unchanged. The current coordinated manifest and SDK/MCP/AI package identities are prepared at v128.0.0 through the existing synchronization machinery. The admitted v127 registry is inherited byte-for-byte through the existing registry-binding schema; no new registry, SQL migration or product law is introduced. Qualification precedes publication. No release attestation is issued for a failed umbrella gate.

The coordinated `@receiz/sdk`, `@receiz/mcp-server` and `@receiz/ai-skills` distribution preserves durable proof memory: **first admission only, then append forever**. The release reader and distribution identity cannot replace the enclosing source or rewrite admitted history.
