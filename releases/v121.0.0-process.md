# Receiz v121.0.0 Release Process

## Goal

Freeze source-first continuity as one coordinated v121 boundary without rewriting historical proof objects or compatible protocol routes.

## What Worked

1. Generate the immutable v121 registry from the exact v120 digest.
2. Coordinate package, ruleset, operation-matrix, AI-manifest, documentation, visible release, and service-worker identities.
3. Pack the exact SDK, MCP, and AI Skills artifacts used by Academy.
4. Run focused continuity, local-truth, profile, settlement, verification, governance, and v121 release-lock checks.
5. Run the full release freeze.
6. Commit the qualified tree and create the immutable `v121.0.0` tag.
7. Generate and verify signed attestation when governance signing credentials and approvals are present.
8. Publish packages, deploy, and run production smoke as separately recorded actions.

Every step must preserve the `@receiz/sdk` durable-memory rule: **first admission only, then append forever**.

## What Did Not Work

Allowing representation confirmations into proof, identity, Settlement, or navigation hot paths caused visible continuity regressions even when the underlying source proof remained valid.

## Practical Rule For Future Work

Paint known sealed or verified truth immediately, append only verified additions, and run server/database distribution beneath the settled surface without giving either authority.

## Standalone qualification boundary

The immutable standalone predecessor is local tag `v120.0.0` at
`09dda2dcf2ff478138fd3760f6186baa9a15b2d3`. The coordinated application
source is pushed `origin/main` commit
`030af97a9b4ced783351d9d13ce1602553021b24`; its Git history is not conflated
with this standalone repository.

Standalone qualification consists of the local release lock, lint/build,
archive parity, relative-link resolution, registry/matrix/range identity,
current-surface coherence, and Git-integrity checks. It does not replace
package publication, deployment, production smoke, production mutation, an
application tag, or signed attestation.
