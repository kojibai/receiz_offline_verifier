# Receiz v113.5.0 Product Truth

The public package surface is `@receiz/sdk`. Durable proof memory remains **first admission only, then append forever**.

## Release Identity

v113.5.0 is a coordinated patch distribution of the fixed `main` tree. The app, SDK, MCP server, AI skills, and constitutional verifier package share version `113.5.0`.

The patch does not create a new constitution. `RECEIZ_RULESET_VERSION`, the v113 registry artifact and digest, artifact-law version, application operation matrix, compiler target, and `>=113.0.0 <114.0.0` compatibility range remain frozen at v113.

## Frozen Primitives

- Offline Record and Seal produces a proof object whose exact sealed bytes remain the strongest source of truth.
- JPEG and native HEIC proof media remain the same proof object across supported iOS Photos normalization and exact-file save paths.
- Offline Verify independently recomputes the verdict before optional append, network, session, or server work.
- Prepared and locally verified proof truth outranks lagging profile/public projections.
- Sports reward closeout remains a settlement primitive with one atomic terminal state.
- Deterministic first paint reuses known truth without rediscovery or fake loading.

## Frozen Invariants

This release must fail if any future change:

- turns offline verification into a network fallback
- lets a Photos rewrite bypass fail-closed canonical-basis verification
- replaces sealed bytes with extracted payload or metadata
- lets a signed-upload retry lose or recreate the prepared proof object
- lets a partial profile projection overwrite stronger saved proof truth
- lets reward retries double-settle or reopen completed closeout
- lets service-worker hydration remount or redefine a settled proof surface
- changes the v113 ruleset or registry merely to label this patch
