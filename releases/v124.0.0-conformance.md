# Receiz v124.0.0 Conformance — Reality Becomes Infrastructure

**The Production Runtime for Verified Civilization.** V124 conformance is valid only when the sealed proof object remains authority and exact authenticated heads bind progression.

## Required local gates

- `pnpm test:v124-release-lock`
- `pnpm test:coordinated-release-identity`
- `pnpm --dir packages/receiz-sdk typecheck`
- focused V124 SDK runtime and adversarial transport tests
- focused OpenAPI, Receiz Docs archive, AI Skills, MCP, package, and release-freeze contract tests
- `git diff --check`

Local gate results are recorded only after each command completes. Passing local conformance does not establish package publication, migration application, deployment, production smoke, scale, adoption, a Git tag, or a signed attestation.

## Authority adversaries

Conformance must reject forged responses from an arbitrary `baseUrl`, request substitution, application/audience substitution, stale or revoked authority, predecessor/head substitution, unknown discriminator/status values, unverified replay, duplicate execution, partial multi-domain writes, private-access leakage, recipient enumeration, and a dependency reported operational without evidence.

## Compatibility

Historical V123 proof object bytes and whole-pulse fields remain unchanged. Durable proof memory remains first admission only, then append forever; newly versioned micro-pulse fields cannot reinterpret V123 schemas.
