# Receiz v115.0.0 Invariant Register

The public package is `@receiz/sdk`. Durable proof memory remains
**first admission only, then append forever**.

## Authority Invariants

- The enclosing sealed artifact remains the strongest proof authority.
- `receiz.native_capture.v1` is a scoped provenance append beneath that
  artifact, not a parallel proof chain.
- `receiz.pbi.proof-object-authorship.v1` is an ordered authorship append to a
  canonically verified predecessor, not ownership transfer.
- UI, session, database, outbox, publication, SDK, MCP, AI, and display state
  remain subordinate.

## Native Capture Invariants

- Only the dedicated operating-system camera ceremony may mint Native Capture
  provenance.
- Ordinary upload or file-picker selection cannot acquire that provenance.
- Native Capture attests the Receiz ceremony; it does not claim
  physical-sensor certification.
- Photo/video source bytes, media kind, MIME, dimensions/duration, ceremony
  commitment, Receiz ID, proof coordinates, and Kai remain bound.
- Photo/video carriers remain format-preserving; caption text cannot replace
  recoverable media truth.
- Text-only preserves frozen v114 Record behavior.

## PBI Authorship Invariants

- The predecessor passes canonical verification before signing is exposed.
- Every append binds exact predecessor digest/head, position, previous append
  head, claim hash, coordinates, Receiz ID, credential identity, verified
  receipt, and Kai/Chronos event.
- Multiple signers append in deterministic order forever.
- Signing cannot change ownership, custody, media, Native Capture provenance,
  or any prior proof/history entry.
- Successor download remains unavailable until the successor independently
  passes canonical verification.

## Durable Outbox Invariants

- Local accepted proof settles before optional publication.
- Corrupt durable payloads fail closed with zero writes.
- Every pending proof is preserved without cap or eviction.
- Active flush drains same-run admissions through bounded quiescence.
- The bound cannot discard remaining work; later retry preserves it.
- Compaction removes only exactly acknowledged reconciliation.

## Verification Invariants

- Standalone, Studio, and `/verify` use the same canonical verifier runtime.
- Verification begins with the enclosing artifact before capture/authorship
  projection.
- Signature V4, Groth16, artifact binding, ordered authorship, and ownership
  continuity remain coherent.
- No Studio-only root, issuer, allowlist, or bypass exists.

`pnpm release:lock 115.0.0` must require this register. A parallel proof chain,
upload-minted provenance, authorship transfer, reordered history, corrupt-state

release.
