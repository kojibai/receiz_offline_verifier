# Receiz v124.0.0 Security — Reality Becomes Infrastructure

**The Production Runtime for Verified Civilization.** Security preserves the sealed proof object and exact authenticated head as stronger authority than transport, TLS, database, SDK, session, or UI state.

## Release-blocking boundaries

- Every runtime response is cryptographically bound to the exact originating request, application audience, authority session, expected predecessor/head, and returned payload.
- Public/client SDK calls fail closed if the existing Receiz verifier cannot authenticate the response. Arbitrary `baseUrl` JSON and forged committed execution outcomes are rejected.
- Session expiry and revocation are checked before authority-bearing use; refresh cannot expand application audience or scopes.
- Replay/checkpoint validation rejects malformed proofs, wrong predecessors, wrong heads, expired or revoked evidence, unknown discriminators, and unknown statuses before application callbacks.
- Private additions are filtered before hydration and never reveal hidden coordinates, membership, or plaintext to an unauthorized caller.
- Recipient resolution is normalized, consent-bound, rate-limited, non-enumerable, and returns no directory listing semantics.
- Atomic transaction failure advances no accepted domain head and writes no partial world, inventory/material, Settlement, or Reserve state.
- Capability qualification requires operational evidence for every required dependency; object or method presence alone fails qualification.

V124 reuses existing sealed-proof, signature, expiry, revocation, exact-head, and verified-addition primitives. It adds no public authenticator, parallel issuer, generic server authority, application admission, or consumer-specific path.

## Evidence boundary

Repository tests can establish local rejection behavior. They cannot establish production secret custody, migration application, deployment posture, live smoke, scale, adoption, or external operator behavior. Those dimensions remain unperformed or unverified until separately evidenced.
