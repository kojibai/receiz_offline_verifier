# Receiz v122.0.0 Product Truth

## Frozen Primitives

The enclosing proof object is authority. Subject identity is deterministic from its admitted proof digest; ownership, heads, registry/reducer pins, mandates, world events, and value effects append without replacing that object.

Edge bundles carry exact proof and append evidence. Database state is synchronization, coordination, discovery, and recovery only. A weaker remote snapshot cannot replace a stronger held edge head.

Private plaintext, geometry, invite lists, proof material, identities, and metadata remain at the edge. Globally distributed events contain only lawful public exterior state and an envelope digest; ciphertext and recipient wraps are subject-scoped. Revocation blocks future delivery without rewriting history.

Phi is the moved value authority. Settlement and Reserve are exactly two distinct proof-native rails. USD is a canonical deterministic live display whose accepted quote and price-basis digest are pinned in the receipt.

`@receiz/sdk` preserves first admission only, then append forever.

## Institutional Authority Order

1. The enclosing sealed proof object and its exact bytes.
2. Deterministic admitted subject identity and verified edge-held state.
3. Verified append history, participant heads, registry/reducer pins, mandates, and receipts.

5. UI, MCP, AI narration, cache, session, and deterministic USD display.

Every lower layer may transport, recover, filter, explain, or display stronger truth. It cannot create a second identity, ownership, privacy, execution, or value authority. This ordering governs the SDK, MCP server, AI skills, HTTP routes, database migration, Academy reference, and production runtime as one v122 institution.
