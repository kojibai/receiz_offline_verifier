# Receiz v123.0.0 Regression Lessons — Intent Becomes Lawful Action

The coordinated public package surface is `@receiz/sdk`, `@receiz/mcp-server`, and `@receiz/ai-skills`. Durable proof memory remains first admission only, then append forever.

Release date: August 22, 2026

## Intent without execution is not completion

Planning a Phi intent is valuable but does not move value. The completion rail must preserve the same proof, rail, exact heads, canonical price basis, idempotency identity, and zero-write failure law through remote execution.

## Timeout is not failure

An ambiguous transport result cannot safely authorize a replan. Exact lookup by idempotency key must distinguish committed, zero-write, and unknown before any retry.

## Applications must not manufacture canonical authority bytes

Permissive local construction creates security drift. Public world command bytes, command digests, plan digests, authority digests, transaction IDs, and transaction digests belong to SDK-owned planners.

## A carried claim is not current subject state

A historical creature, worker, inventory, or ability artifact cannot outrank current exact-head condition and namespace state. Resolve the named namespaces at the planning head.

## Embedded identity must preserve object authority

The object is authority. Avoiding a browser redirect must not make the server the identity root. Verify the enclosing identity artifact at the edge, bind explicit consent to the application and scopes, then issue only short-lived non-refreshable authority beneath that artifact.

## Value-display convenience must not collapse economic law

Phi moves. USD displays. Settlement and Reserve are different rails. A generic wallet balance abstraction would erase the proof-native boundary and is forbidden.

## Public completeness is curated, not indiscriminate

The public developer surface must expose every intentionally supported external operation and omit internal RPC, table, administrative, session, and media mechanics. Route count alone is not developer completeness.
