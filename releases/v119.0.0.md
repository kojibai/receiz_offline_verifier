# Receiz v119.0.0 — Irreversible Offline Custody

Release date: 2026-08-13

V119 closes the Offline Note custody loop at the proof-object boundary. A qualified installation composes a verified Reserve subtraction and an equal whole-value Note genesis locally, consumes each exact held Note head once, and settles the successor into the receiver's local custody without server, database, chain, session, or global publication authority.

## Shipped outcomes

- `@receiz/sdk`, `@receiz/mcp-server`, `@receiz/ai-skills`, and the independent constitutional verifier share the exact 119.0.0 identity.
- The current registry advances from the immutable v118 registry to the v119 registry without rewriting any historical artifact.
- Qualified local Reserve subtraction and Note genesis preserve conservation: one verified Reserve successor and one equal whole-value held-bound Note successor.
- Offline Send consumes the exact current Note head once; receiver activation is local Settlement.
- Server and database routes may project or globally distribute proof history, but neither creates Reserve, releases value, chooses a lawful successor, nor makes Settlement valid.
- Unqualified installations fail closed for Offline Note creation and Offline Send while canonical verification remains available.
- Historical proof objects remain exact-byte readable, verifiable, and exportable under their own release law.
