## Evidence discipline

- Package publication proves public package coordinates and bytes, not application deployment.
- Database inspection proves observed schema state, not proof-object authority.
- Application HTTP smoke proves a reachable public projection, not authenticated write correctness.
- A Git tag proves a named source coordinate only after it exists and is verified.
- A release attestation binds the evidence declared inside it; it cannot substitute for an unrun gate.

## What Did Not Work

- An untracked repository-local pnpm store can pass package construction and still block npm upload at the final Git-clean check.
- Publishing exact dependents before their dependency creates a temporary install gap; publishing the missing exact dependency closes the graph without republishing immutable versions.
- A failed SQL batch can roll back completely while exposing a legacy-data edge. The corrected profile migration preserved three non-positive-genesis rows as unbound and recovered 1,910 lawful legacy coordinates.
- Package and application compilation can regenerate tracked `dist` output; interrupted lifecycle steps must restore deterministic output before the next Git-clean publish.
- Focused feature suites are not a substitute for the coordinated package gate or release freeze.
