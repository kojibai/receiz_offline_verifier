**The Production Runtime for Verified Civilization.** Deployment supplies durable coordination beneath the sealed proof object; it never promotes a hosting provider, server, database, TLS peer, session, or SDK response into authority.

## Required dependencies

- canonical live Kai bridge from pulses since genesis
- proof/head verifier and application/audience binding
- durable journal and checkpoint compare-and-swap
- durable plan and idempotency recovery storage
- session expiry and revocation resolution
- atomic transaction context spanning declared domains
- private-access filter before hydration
- privacy-safe, rate-limited recipient resolver
- operational evidence probes for every required dependency

The server runtime factory must bind these dependencies once and must report the runtime unqualified when any required dependency is absent or inoperative. Presence is not operational evidence.
