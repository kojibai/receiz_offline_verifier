# Receiz v124.1.0 Regression Lessons

**Reality Becomes Infrastructure — The Production Runtime for Verified Civilization.**

The public `@receiz/sdk` contract keeps durable proof memory **first admission only, then append forever**. Every MCP, AI Skill, browser, and application projection remains beneath that same source law.

## What Regressed

- The latest EPUB could seal and publish but then stalled or failed because already verified Blob bytes were expanded and reconstructed through an unnecessary base64 path.
- Image publication entered video-only playback-material completion logic.
- Large-video heads were visible before public package availability was complete.
- Raw RMC2/RMA3 families entered an RMA2-only decoder.
- A 15-second range timeout also governed whole-artifact download work.
- Failed settlement could remain cached when a viewer unmounted before rejection.
- Authenticated profile state could display 489 while the stronger public proof register displayed 490.
- Immediate post-publication state omitted the existing signature ceremony affordance until refresh.
- Private owner memory could be embedded in delivered cognition frames.
- Transfer receipt reconciliation compared the current resealed receipt to its predecessor digest.
- Genesis progressive video was forced onto whole-artifact settlement because signed-range admission required a successor-only native Record payload.
- Adding market to an unversioned completeness list retroactively demoted Receiz Keys that were complete when sealed.

## Why It Regressed

Representation-specific work crossed primitive boundaries. EPUB parsing, video package availability, range projection, UI cancellation, authenticated snapshots, private cognition, and receipt succession were allowed to act as if they defined proof truth instead of remaining mechanics beneath it.

## Locked Rules

- Exact verified Blob bytes go directly to their reader.
- Media-kind dispatch occurs before video-only publication work.
- Public coordinates follow complete durable package publication.
- Decoder choice follows `manifest.capsuleEncoding`.
- Download lifecycle and range-response lifecycle are distinct.
- Viewer cancellation suppresses React state only; it never suppresses proof invalidation.
- Stronger public/local proof state cannot be downgraded by an authenticated snapshot.
- Private cognition sources stay server-side unless explicitly public.
- Current receipt binding and predecessor-chain binding are separate invariants.
- Genesis signed ranges bind to the Signature-V4 artifact basis and manifest/ledger; a native Record payload is checked when present, never required when absent.
- Completeness domain sets are versioned. V1 remains complete under its original law; V2 adds market.
- Institutional status never substitutes for any of these checks.
