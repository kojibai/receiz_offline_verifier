# Receiz v115.0.0 Product Truth

The public package is `@receiz/sdk`. Durable proof memory remains
**first admission only, then append forever**.

## Frozen Primitives

- The enclosing sealed artifact is the proof authority.
- `receiz.native_capture.v1` is an exact camera-ceremony provenance append.
- `receiz.pbi.proof-object-authorship.v1` is an ordered verified authorship
  append to an already verified predecessor.
- Signature V4, Groth16, artifact binding, ownership continuity, and the
  canonical offline verifier remain the same frozen primitives.
- The v114 profile/economy composite proof objects remain immutable historical
  and current application truth beneath the additive v115 registry.

## Frozen Invariants

The release fails if any path:

- grants Native Capture provenance to an ordinary upload
- calls Native Capture physical-sensor certification
- parses capture/authorship before verifying the enclosing artifact
- exposes signing before canonical predecessor verification
- changes ownership, media, provenance, or prior history during PBI signing
- reorders, replaces, truncates, or mutates prior authorship
- exposes a successor download before canonical successor verification
- waits for network publication before local proof settlement
- normalizes a corrupt durable outbox into empty truth
- snapshots an active flush once and strands same-run admissions
- lets a UI, session, database, MCP response, or AI instruction outrank sealed
  artifact truth
- weakens the frozen v114 Record/Seal/ownership/verifier behavior

## Release Gates

Required gates include the v114 offline freeze, v115 Studio suite, real browser
qualification evidence, local PBI/outbox contracts, document-seal and
verification conformance, SDK/MCP/AI distribution builds and tests,
deterministic/primitive/repo-only/visual contracts, production build, golden
path, umbrella release freeze, governance checks, and release attestation.

## Residual Risks

- Physical iPhone Face ID/native chooser evidence remains external and unclaimed.
- The three production SQL migrations named by the release checklist remain
  unapplied until explicitly authorized and run in timestamp order.
- Package publication, git tag/push, deployment, and production smoke remain
  external actions and are not claimed.
- Any contradictory later screenshot or downloaded artifact overrides these
  passing contracts and blocks release.
